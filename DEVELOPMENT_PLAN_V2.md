# SiteOwl XR — Master Development Plan v2
> Generated by code-reviewer + planning-agent audit. All fixes tracked here.

## Architectural Decisions (Decide Before Phase 1)

| Decision | Choice | Rationale |
|---|---|---|
| **A Camera API** | `WebCamTexture` (Unity built-in) | Windows.WebCam is HoloLens-only; won't work on VIVE XR Elite (Android) |
| **B JSON → Unity** | `BUILD.bat` runs Python → copies to `Assets/StreamingAssets/Data/` | One-step automated build |
| **C AI trigger point** | Post-capture (Option B) | Photo saved first, AI runs on file, user confirms before CSV write |
| **D Metadata persistence** | Sidecar `survey_metadata.json` | Preserves audit trail without touching SiteOwl CSV schema |
| **E Session management** | `SurveySession` serialized on every capture | Enables multi-day surveys, crash recovery |
